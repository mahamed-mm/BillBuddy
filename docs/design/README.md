# Design Specs

Design specs written by the `ui-designer` agent and gated by the `design-reviewer` agent. See [AGENT-SYSTEM.md](../AGENT-SYSTEM.md).

- One file per feature: `<phase>-<feature-slug>.md` (e.g. `2A-unequal-splits.md`)
- A spec must be **APPROVED** by `design-reviewer` (Mode A) before any UI task that depends on it is implemented
- Specs use only tokens from [STYLE-GUIDE.md](../STYLE-GUIDE.md); new tokens are marked `(proposed)` until approved
